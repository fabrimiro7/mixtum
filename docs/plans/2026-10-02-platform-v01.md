# ExecPlan — Mixtum Platform v0.1

Per lo stato consolidato e l'ordine di prosecuzione sul secondo Mac, partire da [Stato e roadmap handoff — 3 ottobre 2026](2026-10-03-stato-e-roadmap-handoff.md). Questo file conserva la cronologia tecnica; alcune limitazioni delle sezioni iniziali sono state risolte nelle sezioni successive.

## 1. Goal

Consegnare una piattaforma installabile con Django 6.1.1, Angular 22.2.1/CLI 22.2.0, Tailwind 4.3.3, Keycloak, workspace isolati, plugin Django/Angular locali o esterni e creazione di istanze senza fork.

## 2. Non-goals

AI/RAG, configuratore UI, marketplace e rollout pubblico sono consegne successive.

## 3. Current state

Baseline A0–A3 eseguita. La consegna 1 ha portato Django a 6.1.1, entrambi i frontend ad Angular 22.2.1/CLI 22.2.0 e Tailwind a 4.3.3. La consegna 2 è in corso: backend Keycloak, identity link, workspace enforcement e Console OIDC sono implementati e testati localmente, ma manca la prova con Keycloak reale. Il plugin example è interno al repository. Console e Public Frontend restano applicazioni distinte. Il working tree contiene modifiche preesistenti da conservare.

## 4. Target architecture

Extension → Plugin → Platform → Core. Il progetto istanza compone app Django, route e navigation Console attraverso contratti pubblici. Il backend conserva app label e migration; Angular usa librerie standard con peer dependency. Keycloak possiede identità/sessioni, Mixtum appartenenze workspace e ACL di dominio.

## 5. Security impact

Validare token (firma, issuer, audience, expiry, subject), negare auto-link per email, verificare membership e oggetti correlati server-side, non esporre secret al browser. Test negativi cross-workspace e revisione pre-release.

## 6. Data/migration impact

Ogni schema change passa da migration additive, con test e recovery. Gli utenti legacy non sono associati automaticamente. Il test di plugin esterno conserva app label e dati esistenti.

## 7. Deployment impact

Upgrade e build pulita prima del deployment. Migration come job/processo esplicito. Immagini senza secret; servizi opzionali solo su richiesta; backup/ripristino provati nello staging dedicato.

## 8. Milestones

1. Stack aggiornato e CI verificabile: Django 6.1.1, Angular 22.2.1/CLI 22.2.0, Tailwind 4.3.3.
2. Keycloak + due workspace isolati, Console e Public Frontend quando abilitato.
3. Plugin Ticket minimo e Links, libreria Console, checkout esterno, wheel/npm, reload locale.
4. Template istanza, generatore leggero, skill agente e release staging v0.1.
